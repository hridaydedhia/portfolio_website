# Hriday Dedhia — Personal Portfolio & Engineering Showcase

A personal engineering portfolio and interactive case study platform designed with a high-contrast dark aesthetic, warm orange accents, mathematical precision, and smooth animations. Built to showcase projects across **Quantitative Finance**, **Machine Learning & AI**, and **Software Engineering**.

---

## 🌟 Key Highlights & Features

- **Hero & Identity Stage**:
  - Interactive profile showcase with dynamic audio intro player.
  - Quick-access social links (GitHub, LinkedIn, Email, Resume).
  - Terminal-inspired status badge, live local timestamp, and real-time interactive coordinate tracking.

- **About & Technical Domain Matrix**:
  - Narrative breakdown covering software engineering, AI/ML heuristics, and quant finance focus areas.
  - Interactive 5-domain technical matrix (Software Dev, AI & Data Science, Quant Finance, Systems & Cloud, Creative Direction).
  - Live SVG mathematical schematics and caliper graphics for each domain.

- **Interactive Project Case Studies & Deep-Dive Modal**:
  - Editorial project cards with custom SVG risk-return curves, SML lines, and prediction charts.
  - **Flagship Project**: Markowitz Portfolio Optimization Model (Efficient Frontier, Sharpe Tangency).
  - **Supporting Projects**: CAPM Model, StockMaster (Real-Time Predictive Inventory), and PaisaDiary (1st Place Hackathon Winner).
  - Cinematic portal transition to comprehensive case study views with interactive charts, architecture breakdown, metrics, tech stacks, and source links.

- **Education & Experience (Interactive Progression Timeline)**:
  - 4-stage chronological timeline covering High School (Euro School), Junior College (IDUBS / IITians Spectrum), Engineering (D. J. Sanghvi College of Engineering), and Leadership Committees (DJS Antariksh, DJS Dhadak, DJS eXpress, DJS Compute).
  - Animated stat counters for competitive examinations (JEE Mains, JEE Advanced AIR 25,730, MHT-CET).
  - Expandable / in-place unfolding stage cards with detailed achievements, coursework, and certifications.

- **Contact & Communication**:
  - Functional contact channels and social connect hubs.
  - Responsive layout designed for desktop, tablet, and mobile displays.

---

## 🛠️ Built With

### Core Technologies
- **HTML5 & Vanilla JavaScript (ES Modules)**: High-performance DOM manipulation, zero unnecessary framework bloat, and smooth browser rendering.
- **CSS3 & Tailwind CSS**: Custom design system utilizing CSS variables, responsive grid layouts, backdrop filters, and custom animation curves.
- **Vite**: Modern frontend tooling and lightning-fast local development server.

### Libraries & Dependencies
- **Motion / Lucide Icons**: Smooth SVG rendering and interface icon set.
- **Node.js / Express**: Server runtime environment and API structure.

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (version 18 or higher) and `npm` installed.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/hridaydedhia/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:3000` to view the live portfolio.

---

## 📦 Production Build

To build the static assets for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

Or you can view the website on the published URL given: https://hriday-dedhia-protfolio.ai.studio
